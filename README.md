# M Karthikai Lakshmi — Portfolio

A responsive monochrome portfolio built with React, Vite, Motion for React, and Lucide React.

## Included
- Responsive black/ash theme with a light-mode toggle
- Hero, About, Skills, Projects, Experience, Education, and Contact sections
- GitHub and LinkedIn links
- Six project cards with working category filters
- Responsive mobile navigation
- Reduced-motion support
- SEO metadata and a custom favicon

## Requirements
- Node.js 18+ recommended
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite in your terminal.

## Production build

```bash
npm run build
npm run preview
```

The production output is generated in `dist/`.

## Deploy to Vercel
1. Create a GitHub repository and push this project.
2. Sign in to Vercel and import the repository.
3. Use the Vite framework preset.
4. Build command: `npm run build`
5. Output directory: `dist`
6. Deploy.

## Personalize before publishing
- Review the project descriptions and technology badges in `src/data/projects.js` against each repository README.
- Confirm that `karthikailakshmi46@gmail.com` is the correct email address for public display. Update the email link in `src/App.jsx` if needed.
- Add verified education institution and dates if desired.
- Add live demo links only for projects with working demos.
- Project cards currently link to the real repository URLs supplied for this portfolio.
- No GitHub API token or backend is required for this starter.
